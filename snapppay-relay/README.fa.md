# راه‌اندازی رله اسنپ‌پی روی هاست ایرانی

سایت اصلی (سرور خارج) → زیردامنه ایرانی (رله) → `api.snapppay.ir`

1. روی هاست ایرانی یک زیردامنه (مثلاً `snp.example.com`) بسازید و SSL (AutoSSL/Let's Encrypt) فعال کنید.
2. فایل‌های `index.php` و `.htaccess` همین پوشه را در ریشه زیردامنه آپلود کنید.
3. در `index.php` مقدار `RELAY_KEY` را با یک رشته تصادفی طولانی عوض کنید.
4. از پشتیبانی اسنپ‌پی بخواهید **IP هاست ایرانی** را در whitelist قرار دهد (نه IP سرور خارج).
5. افزونه `snapppay-woocommerce-gateway` (نسخه اصلاح‌شده) را جایگزین کنید و در تنظیمات درگاه:
   - آدرس درگاه: `https://snp.example.com/`
   - کلید رله: همان `RELAY_KEY`
6. تست: `curl -i -H "X-Relay-Key: KEY" "https://snp.example.com/api/online/offer/v1/eligible?amount=10000000"` — باید پاسخ JSON اسنپ‌پی (حتی 401) برگردد، نه 403/502 رله.

نکته: callback پرداخت (`returnURL`) همچنان روی دامنه اصلی است و مرورگر کاربر آن را باز می‌کند، پس نیازی به تغییر نیست.
